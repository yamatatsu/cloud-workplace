# ADR 0002: コードの真実の源を git リモートに統一

- Status: 決定
- Date: 2026-09-05

## Context

macbook と VPS 上の OpenCode の双方が同じコードを扱う必要がある。コードをどこに置き、どう同期するかを決める必要がある。

候補:

1. git リモート（GitHub 等）を真実の源とし、双方が clone / push する。
2. VPS を開発の主戦場とし、macbook は薄い SSH クライアントにする。
3. rsync 等で双方向同期する。

## Decision

git リモートを真実の源とする。macbook / VPS の双方が同一リポジトリを clone し、変更は push / pull で同期する。

## Consequences

- プラス: 作業の取りこぼしや競合を git の仕組みで検知・解決できる。
- プラス: 差分・履歴・バックアップを git リモート側に任せられる。
- マイナス: 未コミットの作業は同期されないため、切り替え時にコミット/プッシュを徹底する運用規律が必要。
- マイナス: シークレットやローカル固有ファイルのコミット混入に注意が必要（.gitignore とシークレット管理を参照）。
